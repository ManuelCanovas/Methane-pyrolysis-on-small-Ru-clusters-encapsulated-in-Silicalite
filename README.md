# Supporting Data for: Methane Pyrolysis on Small Ru Clusters Encapsulated in Silicalite

This repository contains the supplementary computational data (DFT calculations and Microkinetic Modeling) associated with the following publication:

**Title:** Methane Pyrolysis on Small Ru Clusters Encapsulated in Silicalite: DFT and Microkinetic Modeling Study
**Journal:** ACS Catalysis
**DOI:** [https://doi.org/10.1021/acscatal.6c01725](https://doi.org/10.1021/acscatal.6c01725)

---

## Repository Contents

The data is organized into two main directories:

- `/DFT-data`: Contains the convergent data useful for checking calculation energies (OSZICAR) and contains the optimized atomic structures (CONTCAR) for the DFT calculations. These files are ready to be used with VASP or visualization software (e.g., VESTA, OVITO).
- `/MKM-inputs`: Includes the input parameters for the Microkinetic Modeling simulations performed in the study.
